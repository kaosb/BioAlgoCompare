# Algorithm Migration Guide

This guide consolidates all algorithm migration checklists.

## Overview

All algorithms have been migrated to v2 with the following features:
- Base class inheritance (MetaheuristicAlgorithm)
- Proper random state management
- Result schema compliance
- Validation system integration

# Análisis comparativo de benchmarks (plataforma VRP)

`solomon_final/` contiene las figuras, el resumen CSV y el informe estadístico
(`stats_report.md`) de la comparación de algoritmos sobre instancias Solomon
VRP: ranking por instancia, comparación por serie y por tipo, tiempos de
ejecución y por iteración, variabilidad y diagrama de diferencia crítica.

Las visualizaciones se generan con `tools/solomon/analyze_solomon_results.py` a
partir del resumen producido por `tools/solomon/run_full_solomon_benchmark.py`.

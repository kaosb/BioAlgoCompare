## Project Overview

BioAlgoCompare is a platform for rigorous statistical evaluation of bio-inspired algorithms applied to the Vehicle Routing Problem (VRP). It implements 18 metaheuristic algorithms (2016-2025) with massive benchmarking capabilities (1000+ runs), advanced statistical analysis, and scientific visualizations.

## Architecture Overview

### Algorithm Structure
All algorithms inherit from `MetaheuristicAlgorithm` (algorithms/base.py) and implement:
- `initialize_population()`: Creates initial solution population
- `execute()`: Main optimization loop
- `update_position()`: Algorithm-specific update logic

Each algorithm also defines an `Individual` class inheriting from base `Individual` with:
- `move()`: Individual movement logic specific to the algorithm
- `fitness()`: Fitness evaluation
- `is_feasible()`: Feasibility check
- `is_better_than()`: Comparison logic (minimization by default)

### Problem Encoding
The VRP problem uses ordinal encoding:
1. Continuous values (0-1) are generated by algorithms
2. Values are sorted to create a permutation of customer visits
3. Routes are constructed respecting vehicle capacity constraints
4. Distance/cost is calculated based on the decoded routes

### Key Components Integration

**Algorithm → Problem Flow:**
1. Algorithm generates continuous positions
2. VRPProblem.decode_solution() converts to routes
3. VRPProblem.evaluate() calculates fitness with penalties
4. Algorithm updates based on fitness feedback

**Benchmarking System:**
- `utils/benchmarking.py`: Core benchmarking with metrics collection
- `utils/improved/enhanced_benchmarking.py`: Adds checkpointing and massive runs
- Results stored as BenchmarkResult objects with statistical metrics

**Statistical Analysis Pipeline:**
1. Data collection via benchmarking
2. `utils/statistical_analysis.py`: Basic statistical tests
3. `utils/improved/enhanced_statistics.py`: Advanced tests (Friedman, Nemenyi)
4. `utils/advanced_statistical_analysis.py`: Effect sizes, CD diagrams

## Important Patterns

### Adding New Algorithms
1. Create new file in `algorithms/` directory
2. Import and extend `MetaheuristicAlgorithm` and `Individual` from base.py
3. Implement required abstract methods
4. Add to ALGORITHMS dict in scripts/analyze.py
5. Follow seed initialization pattern for reproducibility

### Running Experiments
1. Use `--seed` parameter for reproducible results
2. Use `--parallel` for faster execution on multi-core systems
3. Use `--resume` with massive benchmarks to handle interruptions
4. Results automatically saved with timestamps

### Testing Patterns
- Unit tests for individual components in `tests/unit/`
- Integration tests for algorithm-problem interaction
- Convergence tests verify algorithm behavior over iterations
- All tests should respect seed for deterministic behavior

## Critical Configurations

### Ruff Linter Settings (pyproject.toml)
- Line length: 88 (Black compatible)
- Excludes: scripts/, utils/improved/, legacy code
- Ignores: F401, E501, E712, E741, F841, F823, E722, F811
- Target: Python 3.8+

### Test Configuration (tox.ini)
- Coverage targets: algorithms, problems, utils, scripts
- Test discovery: tests/ directory, test_*.py files
- Markers: "slow" for long-running tests

### Algorithm Parameters
- Default iterations: 100
- Default population: 30-40
- Massive benchmarks: 1000 runs minimum
- Statistical significance: p < 0.05
